This sketch uses CSS to display a full page background image for your webpage.

The CSS background-image property sets a background image for an element, in this case the html element. In this line, the CSS url() function's value should be a path to an image file that will be set as our background.

The background-size property tells our webpage how to size the background image. In this example it is set to "cover" so the image will be stretched to cover the entire page.

The background-attachment property controls whether or not the image will scroll with the page. Here, it is set to "fixed" which will keep the image in the same spot as the user scrolls on the page.

The background-position property sets the position of the background image. In this example it is set to "center", which will keep the image centered on the screen.

The background-repeat property will tell the page whether or not to repeat the image. By default, the image will repeat along the x and y axis. In this example it is set to "no-repeat" which will keep the image from repeating.
