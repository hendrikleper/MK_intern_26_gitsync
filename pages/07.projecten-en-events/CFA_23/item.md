Deze eerste workshop is een korte eerste kennismaking met het schijven van computer-code. We gebruiken hiervoor het programma [Context Free](https://www.contextfreeart.org/). De tutorial & files vind je [hier](https://github.com/theBlackBoxSociety/CodeCrashCourses/blob/master/CFA.md).

**Code is ..**
☞ Fast
    - simple operations executed fast
    - [Robo Sumo](https://www.youtube.com/watch?v=QCqxOzKNFks&ab_channel=RobertMcGregor)
☞ Patient
    - large amounts of repetitions, iterations
☞ Does not get bored
    - [Every Icon](http://numeral.com/appletsoftware/eicon.html)
☞ Dumb
    - doesn’t question the instructions
☞ An intermediary
    - a way to interface with machines
    - a hybrid between human and machine thinking
    - different than the human brain
    - a person reading a book vs a computer reading a script
    - code makes you think in another framework. Similar to talking in another language.
☞ Flavourful
    - several languages, each with their own goals and platforms in mind.
    - HTML, PHP, SQL
    - Python
    - C++ (arduino)
    - [Brainfuck](https://www.youtube.com/watch?v=hdHjjBS4cs8&ab_channel=Fireship)
    - Gcode
